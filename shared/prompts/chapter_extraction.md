# 章节拆分提示词

## 任务描述

将小说文本自动拆分为结构化的章节。

## 输入

- 完整的小说文本

## 输出要求

输出 JSON 格式的章节列表：

```json
{
  "chapters": [
    {
      "id": "ch_001",
      "title": "第一章 意外的相遇",
      "content": "【原文内容】...",
      "order": 1,
      "summary": "主角在咖啡店遇到神秘女子...",
      "characters": ["char_001", "char_002"],
      "scenes": ["scene_001"]
    }
  ]
}
```

## 拆分规则

1. **识别章节标题**
   - 中文：第X章、第X节、Chapter X
   - 自动提取标题作为章节名
   - 无标题的自动编号

2. **章节内容**
   - 保留完整的段落内容
   - 不进行缩减

3. **概要生成**
   - 每章生成 1-2 句话的简要概括
   - 包含主要人物和事件

4. **角色/场景关联**
   - 列出本章出现的角色ID
   - 列出本章涉及的场景ID

## 注意事项

- 识别并保留章节分隔标记
- 处理多级标题（如卷、章、节）
- 对于超长章节，考虑进一步拆分
