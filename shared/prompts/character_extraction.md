# 角色提取提示词

## 任务描述

从小说文本中提取所有出场角色信息。

## 输入

- 小说文本内容

## 输出要求

输出 JSON 格式的角色列表，每个角色包含：

```json
{
  "characters": [
    {
      "id": "char_001",
      "key": "xm",
      "name": "小明",
      "color": "#3498db",
      "gender": "male",
      "age": "20岁",
      "personality": "阳光开朗，乐于助人",
      "appearance": "身高180cm，黑色短发，穿白色T恤",
      "role": "protagonist"
    }
  ]
}
```

## 规则

1. **key 命名规则**
   - 必须使用英文拼音缩写（如 xm = 小明，xh = 小红）
   - 英文角色直接用英文名（如 alice, bob）
   - 多个相同拼音开头加数字区分（如 zhang1, zhang2）

2. **color 分配规则**
   - 主角：蓝色系（#3498db, #2980b9, #1abc9c）
   - 主要配角：绿色系（#27ae60, #2ecc71）
   - 反派：红色系（#e74c3c, #c0392b, #e67e22）
   - 其他角色：紫色/灰色系（#9b59b6, #95a5a6）

3. **role 类型**
   - protagonist（主角）
   - supporting（配角）
   - antagonist（反派）
   - minor（龙套）

## 注意事项

- 仔细阅读全文，找出所有有台词或重要行为的角色
- 不要遗漏任何有名字的角色
- 对每个角色给出简洁但有区分度的描述
